# tachi-lens v0.3.4

v0.3.4 repairs recovery from intermittent chat translation failures.

## Fixed

- Transient provider, network and invalid-response failures receive bounded automatic retries with backoff and jitter. Rate-limit cooldowns remain respected, and fresh messages retain queue priority.
- Exhausted failures show a sanitized reason and a manual retry control. Authentication and configuration failures require corrective action and are not retried automatically.
- Missing or mismatched runtime responses cannot mark a message successfully translated. Recovery preserves original chat text and avoids duplicate translation and warning nodes.

## Upgrade notes

Reload Twitch pages after updating the unpacked extension so the new Content Script is active. Provider credentials and chat/speech settings remain local and retain their existing behavior, including the shared provider credentials already merged on main.

Validation uses privacy-safe synthetic chat and mocked provider responses. This release does not claim live paid-provider compatibility, completion of the separate recycled-row issue #207 or real speech validation #181. This GitHub release does not imply Chrome Web Store publication.
