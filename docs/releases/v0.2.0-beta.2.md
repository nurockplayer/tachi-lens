# tachi-lens v0.2.0-beta.2

發佈日期：2026-08-06  
類型：Pre-release

這是 `v0.2.0-beta.1` 之後的第二個測試版本，整合 40 個新的 commits。重點是把核心翻譯流程從「能運作」推進到可持續驗證、可診斷、可恢復的狀態，同時為目標語言跳過與持久快取建立後續整合基礎。

## 主要更新

### Packaged Extension E2E 與真實 Twitch Canary

- 新增 Playwright MV3 測試架構，從實際建置後的 `dist/` 載入 Extension。
- 驗證 Service Worker 啟動、Content Script 注入與完整翻譯流程。
- 新增 mocked DeepSeek happy path，覆蓋 Twitch DOM → Service Worker → provider → translated DOM。
- 新增 Popup 設定持久化與 API key masking 測試。
- 新增 `below`、`hover`、`collapse` 三種顯示模式的真實瀏覽器回歸測試。
- 新增 Service Worker termination 後恢復翻譯的測試。
- PR CI 現在會執行 packaged-extension E2E，失敗時上傳 Playwright artifacts。
- 新增每日執行的 real-Twitch DOM compatibility canary，並保留隱私安全的失敗診斷。

### Translator batching 與單一飛行排程

- 將 batching 改為固定 300 ms window，最多 10 則訊息一批。
- 一個 Translator 實例同時最多只執行一個 provider batch request。
- 新工作可在 active batch 期間繼續排隊，不會平行啟動第二個 provider batch。
- partial batch 會保留最舊訊息原始的 `enqueuedAt + batchWindowMs` deadline。
- deadline 若在 active batch 期間到期，會在目前 batch 結束後立即處理。
- 加強 FIFO、burst batching、provider concurrency 與 failure-drain regression coverage。

### Gemini quota health 診斷與人工修復

- Popup 新增 Gemini quota health 區塊，區分 healthy、cooldown、clock rollback、untrusted migration、malformed snapshot 與 unsupported version。
- 只在可信的情況下顯示 provider day、cooldown end 與 recovery time。
- unsafe quota state 會清楚說明 Gemini 暫停使用，但 DeepSeek overflow 仍可運作。
- 新增兩步確認的 quota-state repair action。
- 修復只重設 Gemini quota accounting，不會刪除 API keys、一般設定、頻道設定或翻譯快取。

### 本機語言與中文字體判定基礎

- 新增零網路、零額外 dependency 的本機語言／script 判定模組。
- 支援 Chinese locale family、簡體／繁體 evidence、Kana、Hangul 與 mixed-language 保守判斷。
- 新增 `skip_all_chinese` 與 `translate_other_script` 設定型別。
- 設定已接入 global、per-channel、Service Worker 與 Content Script settings plumbing。

> 注意：這一版尚未把該判定接入實際 `translate_request` skip flow，也尚未在 Popup 顯示控制項。完整功能由 #55 與 #57 追蹤。

### IndexedDB 持久快取基礎

- 新增 canonical translation identity，隔離 source text、target language、provider、model、source hint 與 contract version。
- 新增 versioned IndexedDB translation-cache adapter。
- 新增 7 天 TTL、500 entries 上限與 deterministic oldest-first eviction。
- 過期、格式錯誤或 contract-incompatible records 不會被當成有效 hit。
- 只保存成功翻譯與必要 metadata，不保存 API key、username、channel、provider body 或其他 Twitch metadata。

> 注意：這一版尚未把 IndexedDB 接入實際 L1/L2 read-through／write-through request path。完整整合由 #104 與 #105 追蹤。

### 其他可靠性與維護改善

- 加強 provider-specific error preservation 與 retry timing。
- 新增 privacy regression coverage，確保測試 artifacts 與 diagnostics 不洩漏敏感資料。
- 更新 README、agent governance 與 issue template，強化維護範圍與 review 判定規則。
- 區分真實 review findings 與 quota exhausted、review skipped、auto review disabled 等 bot notices。

## 驗證

本版本發佈 workflow 會重新執行：

- `pnpm install --frozen-lockfile`
- `pnpm lint`
- `pnpm test`
- `pnpm build`
- `pnpm test:e2e`

最近的 `main` CI 與 scheduled Twitch Canary 均已成功。

## 已知限制

- 日本語頻道多則普通聊天訊息未翻譯的案例仍在 #37／#101 進行 evidence-based diagnosis。
- Translator queue failure recovery 與 exactly-once settlement 的最後階段 #52 尚未完成。
- 目標語言訊息 skip 尚未接入 Content Script，Popup 也尚未提供 Chinese variant 控制項。
- IndexedDB adapter 尚未接入實際 translation request path。
- 這仍是 beta prerelease，不應視為正式穩定版 `v0.2.0`。

## 安裝

1. 從 GitHub Release 下載 `tachi-lens.zip`。
2. 解壓縮檔案。
3. 開啟 `chrome://extensions`。
4. 啟用「開發人員模式」。
5. 選擇「載入未封裝項目」，載入包含 `manifest.json` 的資料夾。

## 升級注意事項

- API keys 與一般設定仍保存在本機 `chrome.storage`。
- Chrome manifest 使用 numeric `version: 0.1.0.2`，顯示版本為 `0.2.0-beta.2`，排序高於 beta.1 且低於未來正式版 `0.2.0`。
- 若偵測到不可信的 Gemini quota snapshot，可在 Popup 中使用兩步確認修復；DeepSeek overflow 不受影響。
