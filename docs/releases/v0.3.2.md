# tachi-lens v0.3.2

v0.3.2 updates Gemini support to the current Gemini 3 generation while preserving compatibility with existing Gemini 2.5 settings.

## Updated

- Added Gemini 3.8 Flash (`gemini-3.8-flash`) as the default Gemini chat model.
- Added Gemini 3.8 Flash as the default model for new speech-subtitle configurations.
- Kept Gemini 2.5 Flash and Gemini 2.5 Pro available so existing persisted selections continue to work without migration.
- Added a Gemini 3.8 quota profile alongside existing 2.5 profiles.
- Configured Gemini 3 generateContent requests with `thinkingLevel: low` for lower-latency, lower-token real-time translation.
- Added focused chat and speech regression coverage for Gemini 3.8.

## Upgrade notes

Existing users who explicitly selected a Gemini 2.5 model keep that selection. Selecting Gemini without an existing model preference now defaults to Gemini 3.8 Flash.
