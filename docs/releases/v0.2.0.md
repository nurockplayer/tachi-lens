# tachi-lens v0.2.0

Release date: 2026-08-09  
Type: Stable

`tachi-lens v0.2.0` is the first stable release of the 0.2 line. It promotes the functionality validated throughout the beta cycle after the core translation, reliability, caching, language-handling, diagnostics, browser E2E, and release-pipeline work reached a stable milestone.

## Highlights

### Reliable Twitch chat translation

- Hardened translation queue failure recovery and exactly-once request settlement.
- Bounded the Content Script translation queue and deterministically removes obsolete or oldest pending work under sustained load.
- Invalid, empty, whitespace-only, malformed, or incomplete provider translations remain retryable instead of being permanently marked as processed.
- Added regression coverage for initial scan, retry scan, display modes, Service Worker restart recovery, and packaged-extension behavior.
- Completed the Japanese missing-translation investigation tracked by #101 and parent #37, with confirmed failure paths addressed by focused follow-up fixes.

### Efficient provider usage

- Deduplicates identical translations within a flush using the canonical translation identity.
- Coalesces equivalent in-flight work and verifies cleanup after both success and failure.
- Adds privacy-safe aggregate diagnostics for batch deduplication, in-flight coalescing, queue overflow, and obsolete-work drops.

### Persistent translation caching

- Production request path now uses L1 in-memory cache followed by L2 IndexedDB before invoking a provider.
- L2 hits are promoted to L1 and survive Manifest V3 Service Worker restarts within TTL.
- Successful provider results write through to IndexedDB without allowing cache failures to break successful translations.
- Expired, malformed, or contract-incompatible records safely fall back to the normal provider path.

### Language-aware message handling

- Messages already in the configured target language are skipped before a `translate_request` reaches the Service Worker.
- Chinese target locales expose explicit message-handling controls, including `skip_all_chinese` and `translate_other_script`.
- Local language/script detection remains network-free and dependency-free.

### Quota and provider resilience

- Gemini quota accounting, cooldown handling, rollback detection, health diagnostics, and recovery controls are integrated with DeepSeek overflow behavior.
- Provider-specific errors and retry timing are preserved more reliably through the translation pipeline.

### Quality and release engineering

- Real ESLint, TypeScript typechecking, Vitest, production build, and packaged-extension Playwright E2E are enforced in CI.
- Scheduled Twitch compatibility canary can select a live channel dynamically from configured candidates.
- The permanent CD publisher validates release metadata, runs the complete release gate, creates an annotated tag, packages `tachi-lens.zip`, and publishes the GitHub Release idempotently.
- Selective Lightweight SDD is adopted for shared/high-impact contracts while GitHub Issues remain the focused implementation unit.

## Validation

The stable release publisher validates the exact release commit with:

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm test:e2e`
- ZIP packaging and `manifest.json` content verification

## Installation

1. Download `tachi-lens.zip` from this GitHub Release.
2. Extract the archive.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Choose **Load unpacked** and select the extracted directory containing `manifest.json`.

## Upgrade notes

- Existing API keys and settings remain stored locally in Chrome storage.
- Chrome manifest `version` and displayed `version_name` are both `0.2.0`.
- This release is published as a normal stable GitHub Release, not a prerelease.
