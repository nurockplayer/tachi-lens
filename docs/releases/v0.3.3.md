# tachi-lens v0.3.3

v0.3.3 introduces validated remote model policy for Gemini chat, Gemini speech and DeepSeek chat. Later compatible recommendation changes and rollbacks can use a reviewed policy update without rebuilding the extension.

## Updated

- Added Auto / Recommended model selection while preserving every saved concrete model pin.
- Added a service-worker-only policy reader with strict schema/configuration validation, bounded refresh, cached last-known-good state and a bundled offline fallback.
- Preserved Gemini quota admission, cache model identity, DeepSeek fallback triggers, speech consent/session behavior and privacy contracts.
- Added privacy-safe resolution diagnostics, a scheduled provider catalog drift monitor and credentialed synthetic compatibility probes. Discovery never promotes a model automatically.

## Upgrade notes

The initial reader requires this extension update and adds the `https://raw.githubusercontent.com/*` host permission. The reader fetches only this repository's fixed policy URL; remote data cannot provide code, endpoints, headers or prompts. Existing concrete global, channel and speech selections stay pinned. Choose Auto deliberately to follow recommendations.

See [the model-policy runbook](../model-policy.md) for validation, rollback and the configuration-versus-client-release boundary. This GitHub release does not imply Chrome Web Store publication.
