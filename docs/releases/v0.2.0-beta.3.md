# tachi-lens v0.2.0-beta.3

Release date: 2026-08-08  
Type: Pre-release

This beta focuses on translation correctness, bounded work, persistent caching, language-aware skipping, and a more reliable release pipeline.

## Highlights

### Translation reliability and queue safety

- Hardened Translator failure recovery so queued requests settle exactly once even when settings, API-key lookup, cache writes, or provider calls fail (#125).
- Bounded the Content Script translation queue and deterministically drops obsolete or oldest pending work under sustained load (#126).
- Invalid, empty, whitespace-only, or malformed provider translations now remain retryable instead of being permanently marked as processed (#130).
- Strengthened collapse-mode browser assertions to protect translated-element ownership and exact display restoration (#128).

### Less duplicate provider work

- Identical translations inside one flush are deduplicated using the canonical translation identity and fan out one result to all matching requests (#131).
- Added regression coverage proving in-flight registry entries are cleaned up after success, so settled Promises are not retained (#134).
- Added privacy-safe aggregate diagnostics for batch deduplication, in-flight coalescing, queue overflow, and obsolete-work drops (#136).

### Persistent translation cache

- Integrated the production L1/L2 cache path: in-memory cache first, IndexedDB second, provider only on a full miss (#142).
- L2 hits are promoted into L1 and avoid provider work.
- Successful provider results are written through to IndexedDB without allowing cache-layer failures to break translations.
- Expired, malformed, or contract-incompatible records safely fall back to the existing provider path.

### Language-aware message handling

- Messages already in the configured target language are skipped before any `translate_request` reaches the Service Worker (#135).
- Popup now exposes Chinese message handling options for Chinese target locales, including `skip_all_chinese` and `translate_other_script` (#127).

### CI, canary, and release infrastructure

- Added a real ESLint pipeline and clarified CI command responsibilities (#138, #140).
- Scheduled Twitch canary can dynamically select a live channel from configured candidates instead of depending on one fixed channel (#143).
- Added the permanent idempotent CD publisher that validates release metadata, runs the full gate, creates an annotated tag, packages `tachi-lens.zip`, and publishes the GitHub prerelease (#146).
- Adopted Selective Lightweight SDD while keeping GitHub Issues as the implementation unit and preserving parallel implementation throughput (#145).
- Adopted English as the canonical language for new technical artifacts (#147).

## Validation

The release publisher reruns the complete publication gate on the exact release commit:

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm test:e2e`
- ZIP packaging and `manifest.json` content verification

## Known limitations

- The Japanese-chat missing-translation investigation tracked by #101 remains open. The invalid-response retry fix in #130 removes one confirmed permanent-skip path, but this release does not claim that every #101 reproduction is resolved.
- This remains a beta prerelease and is not the stable `v0.2.0` milestone.

## Installation

1. Download `tachi-lens.zip` from this GitHub Release.
2. Extract the archive.
3. Open `chrome://extensions`.
4. Enable Developer mode.
5. Choose **Load unpacked** and select the extracted directory containing `manifest.json`.

## Upgrade notes

- Existing API keys and settings remain stored locally in Chrome storage.
- Chrome manifest numeric version is `0.1.0.3`; the displayed version is `0.2.0-beta.3`.
