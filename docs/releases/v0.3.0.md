# tachi-lens v0.3.0

v0.3.0 adds streamer speech subtitles and substantially hardens the extension's runtime controls, translation behavior, and Popup diagnostics.

## Highlights

- **Streamer speech subtitles**: capture Twitch tab audio after explicit user consent, process bounded audio windows through Gemini, and render translated subtitles over the player.
- **Privacy-first speech pipeline**: raw audio is not persisted; capture runs through the MV3 offscreen document and stops on disable, navigation, capture failure, or configured budget exhaustion.
- **Live Popup controls**: critical chat and speech controls now persist and apply immediately, with bounded failure feedback and preserved per-channel precedence.
- **Reliable translation disable behavior**: disabling chat translation now clears pending/debounced/queued work, blocks new provider dispatch, suppresses late results, pauses retries/backlog, and preserves speech independence.
- **Popup dashboard refresh**: compact dark control-center UI, progressive disclosure, improved quota-health states, localized diagnostics, privacy-safe event summaries, and clearer loading/empty/error states.
- **Better Twitch translation semantics**: improved Twitch terminology context and conservative same-target language skipping for Chinese, Japanese, Korean, and confidently detected English chat.
- **Safer validation pipeline**: deterministic risk-based CI keeps full validation for runtime changes while avoiding unnecessary E2E work for docs-only changes.

## Validation

The release line has passed the repository's automated release gates, including lint, TypeScript typecheck, the full Vitest suite, production build/CSP validation, and packaged-extension Playwright E2E coverage.

The real human-action Chrome `tabCapture` → Gemini → subtitle path remains tracked separately in Issue #181 for continued real-world validation. This does not change the shipped implementation or automated release gates.
