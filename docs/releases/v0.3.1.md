# tachi-lens v0.3.1

v0.3.1 is a compatibility hotfix for DeepSeek's renamed Flash model identifier.

## Fixed

- Updated the canonical DeepSeek Flash model ID from `deepseek-v4-flash` to `deepseek-flash`.
- Restored direct DeepSeek translation and Gemini → DeepSeek fallback after the upstream model rename.
- Updated DeepSeek API-key validation to recognize the current Flash model ID.
- Added transparent migration for existing global and per-channel settings that still store `deepseek-v4-flash`.
- Centralized the fallback model on the provider-owned default so future model-ID changes do not leave the translator on a stale duplicated string.

## Upgrade notes

No manual settings reset is required. Existing installations using the old DeepSeek Flash model ID are migrated at the settings boundary when the extension loads.
